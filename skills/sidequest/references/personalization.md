# 从确认方案到独立 Skill

## 交付位置和隐私

默认输出到当前工作区 `.sidequest/private-skills/<name>/`，或用户指定的本地私人位置。
名称使用不含身份信息的英文小写短名，例如 `sidequest-slow-living`，不使用真实姓名或邮箱。

确认卡的确认覆盖本次文件生成与选定的记录方式，不等于同意联网、发消息、建立定时任务或公开文件。不要把个人文件提交到公共仓库。

## 使用生成器

Python 3.9+ 可用时，把用户确认的摘要组织为 JSON，存到本地 `.sidequest/confirmed-plan.json`。不要复制原始聊天或密钥。

```bash
python3 <本技能目录>/scripts/build_personal_skill.py \
  --plan <确认方案的本地 JSON 路径> \
  --output <个人 Skill 的父目录>
```

命令里的路径需替换为实际路径，并按 shell 规则加引号。脚本无网络操作，不会注册 Skill、写入宿主配置或创建自动化。已存在同名目录时停止；要更新既有 Skill，应先阅读实际文件并修改相应部分，保留用户的其他内容，不删除重建。

### JSON 结构

所有字段均必需；这些是精简后的确认结果，不是直接丢给用户填写的问卷。

```json
{
  "name": "sidequest-your-choice",
  "display_name": "我的人生支线",
  "confirmed": true,
  "profile": {
    "main_quest": "用户当前主要投入的事情",
    "motivation": "为什么想开支线，包括纯粹的乐趣",
    "interests": ["已表达的兴趣"],
    "boundaries": ["不希望发生的体验或成本"],
    "learning_style": "用户偏好的呈现和互动方式",
    "tone": "用户喜欢的沟通语气",
    "language": "简体中文",
    "memory": "local"
  },
  "rhythm": {
    "minutes_per_session": 10,
    "sessions_per_week": 2,
    "low_energy_minutes": 2,
    "review_every_sessions": 4
  },
  "quests": [
    {
      "id": "first-quest",
      "title": "已选中的支线",
      "why": "与这个人具体的联系",
      "baseline": "当前起点；未知就明确标为待观察",
      "goal": "用户认可的可感知变化",
      "sessions_per_week": 2,
      "first_step": "预算内的第一个动作",
      "steps": ["后续的小台阶", "下一次可观察的尝试"]
    }
  ]
}
```

`memory` 只能是 `local`（本地精简摘要）或 `session-only`（不追加持久化学习记录）；生成的个人 Skill 本身仍保存这份最小确认方案。
`confirmed: true` 仅在用户确实确认后设置，不代表脚本能替你验证同意。
每条支线的周次数之和不能超过总次数，剩余是可不使用的余量。低精力分钟数可以是 0，表示休息；不能大于正常单次预算。
正数预算并不是对实际耗时的保证，要额外检查动作本身是否可行。默认选少量支线，但不在生成器里强制「最多三条」。

## 没有 Python 或没有文件工具

读取 [入口模板](../assets/personal-skill.md) 和 [陪伴规则](../assets/companion.md)，按以下结构生成相同的自包含内容：

- `SKILL.md`：替换名称与显示名，保留相对引用和有辨识度的触发条件。
- `profile.md`：确认过的画像摘要、共享时间预算、每条支线的理由/起点/目标/第一步/后续台阶、记录方式。
- `progress.md`：空白进度起点，不伪造任何已完成体验。
- `references/companion.md`：复制陪伴规则，避免依赖生成器安装路径。
- `references/delivery.md`：复制 [定时与投递规则](../assets/delivery.md)，仅在用户请求自动联系时使用，不自动创建任务。
- `agents/openai.yaml`：写入显示名、25–64 字符短描述、包含 `$<name>` 的默认提示。允许正常自动选择，不设置显式调用限制。

没有写文件能力时，分别提供上述文件的完整内容与相对路径，说明尚未保存/安装。不要用「已写入」描述代码块。

## 检查与交接

检查前后声明一致：用户选中的主题、所有预算、记录模式、起点与第一步，不可在生成时偷偷加码。
检查没有未替换的模板变量、绝对机器路径、私人联系方式或密钥，所有相对引用存在。确认生成的文件夹在离开本仓库后仍自包含。

交付时提供文件位置、调用示例和一个适合今天的起步建议。只有安装工具实际完成注册后才说「已安装」。持久记录未验证则说明；自动提醒默认未配置。

## 更新已有专属 Skill

`profile.md` 是当前有效方案，`progress.md` 是反馈事实，不拿历史记录覆盖用户现在的选择。
变更方向或长期节奏时给出简短新方案，让用户确认；修改相关段落，保留其他个性化内容。在同意本地记录的前提下，记一行变更原因，不存整段私人聊天。
单次临时降量、跳过或暂停立即执行，不为「确认流程」强留用户；不要自动改成永久新计划。
