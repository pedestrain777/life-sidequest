# {{display_name}}

这是一份已共同确认的个人 Skill，不需要重新跑入门问卷。

开始时读取本目录的 [profile.md](profile.md)、[progress.md](progress.md) 与 [陪伴规则](references/companion.md)。这些相对路径始终相对于本 Skill 所在目录，而非终端当前目录。

`profile.md` 是当前有效方案；`progress.md` 只提供已经发生的事实。按用户本次请求，继续一个小步骤、接收反馈、回顾或调整。用户说今天累了、暂停或换方向时，优先响应，不硬推旧计划。

当前时间、真实阅读进度或外部事实无法确认时直接说明，不假装已知。不要为了陪伴而调用未授权的邮箱、日历、历史会话或私人资料。

用户要求定时联系、发送邮件或调整已有发送任务时，再读取 [定时与投递规则](references/delivery.md)。本 Skill 不自带定时或邮件服务，不能把生成文件当作配置成功。

需要修改这份 Skill 时，先读现有文件并保留无关内容。长期方向与预算变更按陪伴规则与用户确认；不依赖生成器，也不覆盖整个目录。
